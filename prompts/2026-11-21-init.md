# 2026-11-21 — inisiasi proyek

## Prompt (ringkas)
Membangun school management system berbasis SaaS: dokumentasi .md tersimpan di GitHub, push otomatis, struktur tabel tersimpan, bisa dipanggil lewat API dari situs, database online. Tiap sekolah punya subdomain: `/` landing, `/admin` staf, `/siswa` siswa aktif.

## Hasil
- Arsitektur: Supabase (Postgres + RLS + Auth) + frontend satu aplikasi dengan resolusi tenant dari hostname
- Migrasi 001 (skema + RLS) dan 002 (wali, audit, create_school)
- Scaffold Vite, workflow `deploy-db.yml`, `sync.sh`
- CRUD siswa, struktur dipecah per modul
- Dokumentasi, CLAUDE.md, skill proyek

## Keputusan
- Supabase dipilih daripada MySQL + backend sendiri (isolasi tenant via RLS, tanpa menulis CRUD API)
- Cloudflare Pages/Vercel, bukan GitHub Pages (wildcard subdomain)
- Supabase CLI via `npx` (instalasi global npm gagal); untuk perintah migrasi tambahkan `--remote`
- Key frontend memakai publishable key
